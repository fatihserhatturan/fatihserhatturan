## Projects

### [noCap](https://github.com/fatihserhatturan/noCap) · [site](https://fatihserhatturan.github.io/noCap/)

See how a rapper rides the beat. A desktop app for macOS and Windows that separates the vocals,
transcribes them and maps every syllable onto the beat grid, with rhyme groups, pocket timing and
flow metrics. Everything runs locally.

`Python` `Whisper` `Demucs` `librosa` `Electron` `React` `PixiJS`

### [concentrate](https://github.com/fatihserhatturan/concentrate)

A code graph for AI agents. It reads a codebase once and turns it into a queryable graph of files,
calls, HTTP routes, dependency injection, environment variables and database access, then serves it
to agents over MCP. One runtime dependency.

`TypeScript` `Node.js` `MCP` `Static analysis`

### [Beluga Icon](https://github.com/fatihserhatturan/Beluga-Icon) · [demo](https://fatihserhatturan.github.io/Beluga-Icon/) · [npm](https://www.npmjs.com/package/@beluga-icon/react)

1800+ stroke-based SVG icons for React, with built-in animations, visual styles and full TypeScript
support.

`React` `TypeScript` `SVG`
